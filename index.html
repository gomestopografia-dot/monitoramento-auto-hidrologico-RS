ⓘ Informações das fontes
Rio Pardo consulta automaticamente o CSV SACE/SGB da estação 85900000 (guaiba_55) a cada cinco minutos; leituras antigas são identificadas. São Sepé utiliza a estação Camping São Sepé (85623010), conforme correspondência de código retornado pelo ClimaRS. São Borja utiliza Passo São Borja (75780000). São Borja consulta automaticamente o CSV oficial da estação Passo São Borja no SACE/SGB a cada cinco minutos. Se o SACE estiver inacessível, o CSV local é usado somente como histórico e a leitura antiga é sinalizada. Consulte o diagnóstico para verificar se a atualização automática foi confirmada. Se a fonte não devolver leitura recente dessa estação, o painel mostra ausência de medição, sem usar Garruchos como substituta. As demais estações são identificadas pelo nome e município oficial. Se uma estação específica não for localizada, aparecerá “Sem leitura confirmada”, sem utilizar medições de outras cidades. O status é publicado pelo ClimaRS. Leituras recentes obtidas na ANA legado aparecem sem classificação de inundação; dados com mais de 24 horas não são exibidos como atuais. Mapa requer internet.
